# Retired cloud source art

Task 135 removes all clouds at the user's request. Nothing in this folder is
imported or loaded by the current game; do not run earlier integration recipes.
The clear cyan gradient and approved sun now belong to `Content/Sun/`.

`Clouds.blend` retains editable Blender MCP forms in Sunny Clouds Authoring 130
and Sunny Cloud Volumes 134. `export_volumes.py` reproduces `CloudVolumes.fbx`;
the original atlas/recipes and `previous-130.zip` / `previous-132.zip` are source
archives. Runtime cloud assets, materials, shaders, setup, drift and scene
references were removed. Completed preview images are cleaned.

Original project-owned art; free commercial use, modification, redistribution
and sale, without attribution, under `LICENSE.txt`. Retained source ownership
is recursive within `art/clouds/`; see `docs/asset-ledger.md`.
