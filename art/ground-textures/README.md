# Original garden ground

Two original seamless cartoon surfaces: warm soil (2 m tiles) and green short turf (1.25 m runtime tiles). Task 105 currently uses **r8 soil albedo, r7 soil normal/mask and r6 turf**. R8 removes heavy dirt-pattern coating from the existing stones and selects solid mineral faces at projection overlaps. Sunny colors, the 110 stone identities and terrain geometry remain. [Accepted style views](../../docs/development/art-review-105/index.html).
Original Blender MCP work for [Task 77](../../docs/development/tasks/77-ground-textures.md); commercially usable under [LICENSE.txt](LICENSE.txt), without attribution.

- `GroundTextures.blend` retains the original and `Cartoon ground authoring` scenes, editable nodes, wrapped geometry, recipes and the six selected cartoon bakes. Current authoring is described below. Retained 1024px recipes are `scattered_soil.py` (r5 soil), `varied_soil.py` (r4 soil), `living_ground.py` (r3 soil/turf) and `sunny_detail.py` (r2); `cartoon_ground.py` owns the earlier 512px trials and shared source saver. Superseded PNG exports and 40 old packed cartoon bakes were removed at the user's request. Their editable geometry/materials and all recipes remain, so older variants can be rebaked if needed; old receiver image slots are intentionally empty. Preserve Unity `.meta` identities when promoting maps.
- Previous granular soil restoration: `rocky_soil.py`; run `bind_source()`, `create_revision()` only if absent, then `bake(channel)` for `Albedo`/`Normal`/`Roughness`. `rebuild()` regenerates only its owned source. These operations replace the current soil exports, so use them only for an intentional rollback. Set `ROOT` for another checkout.
- Previous olive turf restoration: `create_ground.py`; use `bind_existing()` then `bake_map('Turf', channel)`. Fresh original-source recreation starts with `initialize()` here, followed by `rocky_soil.py`. The obsolete dot-based soil bake is guarded against overwriting the rocky revision. Use `cartoon_ground.save_source()` when retaining both old and cartoon authoring scenes.
- `solid_minerals.py` owns r8: `initialize()` once copies r7 source/relief, retaining all geometry and the matrix. `bake()` creates only the 2048px albedo in `trials/A-Sunny-r8/`; `save_source()` retains editable nodes/geometry and packed images. Stone coating uses restrained uniform warmth sampled from the previous soil bake rather than its aggregate pattern. Use r7 normal/mask and r6 turf unchanged. `settled_soil.py` retains the 110-stone r7 source; `crisp_ground.py` owns r6 turf. Only the six selected PNGs remain under `trials/`; all previous recipes and source geometry/materials remain for editing or regeneration.
- Six 2048-square PNG exports live in `unity/Assets/Content/GroundTextures/`: sRGB albedo, tangent-space +Y normal and linear surface masks. Both masks pack roughness in R and contact occlusion in G; soil B marks stone coverage. Albedo/masks use BC7 and normals BC5, with trilinear mipmaps, Repeat and 16x anisotropy. Their full mip chains require approximately 32 MiB of compressed texture data, versus 8 MiB at 1024px.
- MainGame uses shared `GardenGround`: soil/turf both use world-plane projection with stable position gradients; soil stone selection is restricted to comparably facing axes, with one coherent mineral sample and a narrow filtered boundary instead of whole-face crossfading. Relief is 0.55/0.90/0.40, and the cap keeps its narrow screen-filtered boundary. Grass color/normal/mask project onto cut walls at matching coordinates rather than stretching top UVs. No runtime geometry/colliders are added. `GroundTextureSetup.Configure()` repeats import/material settings and retains r6 shadow/contact quality.
- The asset ledger owns integration/removal boundaries. These textures do not imply a new geological resistance type.

Cleanup retention: `trials/A-Sunny-r8/Soil_Albedo.png`, `trials/A-Sunny-r7/Soil_{Normal,Roughness}.png`, and `trials/A-Sunny-r6/Turf_{Albedo,Normal,Roughness}.png` match the six runtime PNGs. Keep them and existing Unity `.meta` identities. Six final review screenshots remain in `docs/development/art-review-105/images/`; temporary and superseded review images are removed.
