# Just a few peppers — Unity project

Open this folder (`games/just-a-few-peppers/unity`) in Unity Hub with the editor version recorded in `ProjectSettings/ProjectVersion.txt`, currently **6000.6.0f1**. Paths below are relative to this Unity project folder.

**To start the new game, use the [fresh-chat prompt](../docs/development/new-chat-prompt.md) and request [task 1_01](../docs/development/tasks/1_01_unity-foundation-and-walkable-scene.md) or NEXT.** That task supplies a walkable foundation; 1_02–1_05 add the complete crate loop. The agent wires each step and provides its scene/build path, controls, and a short play checklist. See the [numbered queue](../docs/development/tasks/readme.md) for the full work order.

The [current design](../docs/readme.md) is bulk pepper clearing, useful equipment discoveries, one automatic processing line, one finished product, and one storage rack. Winter food and parcels appear through progress-driven presentation, followed by the meal ending. This v4 game is specified but not implemented.

The existing `Assets/Stage0/Scenes/ChushkopekStage0.unity` is an older one-pepper roasting/peeling experiment. Its code and generated assets are disposable reference material; no further hands-on acceptance or routine test reruns are required for it. Historical Chushkopek identifiers remain until implementation replaces or reuses the relevant pieces.

Use the [roadmap](../docs/development/roadmap.md), [status](../docs/development/status.md), [audit](../docs/development/repository-audit.md), [Unity and asset policy](../docs/development/unity-and-assets.md), and [verification rules](../docs/development/testing-and-performance.md) for new work. Stage0's build menu and regenerating scene probe target only the old experiment.
