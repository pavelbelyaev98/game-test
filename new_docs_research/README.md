## The evidence

[Research index](RESEARCH/README.md) lists all four game analyses and their raw review data.

The analyses explain what players experienced. The concept chapters describe the game being made;
earlier research notes do not override later design choices.

## How to update the concept

- Write current rules directly in the relevant chapter, with a short reason where useful.
- Keep related chapters consistent. Use descriptive links when another chapter provides detail.
- Keep unanswered choices in Open Questions; remove them when the answer is documented.
- Preserve the existing short writing style, useful examples and meaningful detail.
- Tune numerical targets in play. Keep implementation details only where they explain the experience.
- **Commit only when the developer explicitly asks.** Leave edits uncommitted for diff review.
- Keep research analyses and raw data separate from concept edits; update navigation when files move.
