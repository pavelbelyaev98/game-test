# Consistent art and asset style

Status: **selected process, unselected final style**. The user requests research and practical comparison of multiple texture packs, repeated until they like a direction, then consistency with that choice. [105](../../development/tasks/105-art-style-texture-trials.md) owns the trials and review artifact. No new assets have been created or imported by this planning change.

## Reference and intended feeling

The preferred reference is JulioVII's [Stylized Grass & Dirt](https://juliovii.itch.io/ftpgrass-dirt), inspected 2026-09-10. Its preview uses broad painterly color patches, warm earth, vivid greens and clearly shaped stones. Treat these as qualities to compare in our excavation, not a selected exact palette or a requirement to use every material.

The creator lists nine PBR materials with base color, roughness, normal and height maps. The page currently says CC-BY and commercial use except reselling; it describes CC0 as a future intention. Verify the included exact license/attribution before any proposed import. Liking this reference is not pack-import approval.

The world should feel deliberately styled and tactile. A partly exposed common object must stand out as a recognizable shape within the ground; texture noise must not camouflage it. Earth, stones, finds, shovel and existing stations should look as though they belong together. The quiet common-find experience cannot rely on a detector to compensate for weak art readability.

## Ownership and boundaries

- `105` owns the shared visual language and evidence from texture trials. Its accepted outcome becomes the style guide here; `57` consumes it for feedback, equipment staging and presentation briefs, without reopening the palette on each task.
- `89` selects the three common objects; `09` applies the style to approved starter assets. `58` chooses setting/material progression and `39` integrates terrain behavior. `08` owns the broader production presentation pass; existing assets are evaluated before proposing replacements.
- Preserve the user's terrain work. Compare specific, independently reversible candidate batches using Blender MCP or approved commercially usable sources. A request to create the task authorizes planning; actual asset additions follow the repository's concrete preview/file/license/approval workflow.
- Keep audio, unrelated scenery and lighting redesign outside these texture trials. Use fixed current lighting to compare candidates; any later selected `68` lighting must preserve the accepted readability and palette.
