# Feature contracts

One contract per live system. Each owns selected behavior, exact decisions, rejected alternatives, open questions and the numbered task IDs that work on it. `docs/idea.md` remains the full concept; read it only when a contract is insufficient.

- [Core gameplay and controls](core-gameplay.md) — loop, persistence, FPS controls, crouch, camera comfort, PC/input settings, menus/HUD.
- [Excavation and terrain](excavation.md) — terrain/digging, cleanup, admin, materials/resistance, experimental modes, passive lighting.
- [Discoveries](discoveries.md) — detector, generation, roster/content, collection, handling/physics, display, find assets.
- [Progression and economy](progression.md) — currency, selling/workshop, shovel, fuel/battery, jetpack, inventory, permanent rewards.
- [Return, rescue and ending](return-and-ending.md) — automatic rescue, warning bands, falls, return aids, ending, achievements.
- [Presentation and art style](presentation.md) — accepted visual direction, environment, matching rules, asset approval.
- [Release and optional systems](release.md) — Windows targets, budgets, qualification gate, deferred optional systems.
