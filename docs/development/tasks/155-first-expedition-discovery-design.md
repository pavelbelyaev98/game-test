# Task 155 - Design reliable first-expedition discovery pacing

Type: design/research. Status: `planned`. Prerequisites: unique purpose `117`, handling `96`/`97`, first roster brief `40`. Does not block creating the first approved models in `42`; its reviewed placement policy precedes that encounter's generation in `45`.

Features: [generation](../../features/backlog/discovery-generation.md), [content](../../features/backlog/discovery-content.md). Context: [both Keep Digging reports and user verdict](../../research/keep-digging-lessons.md). Consumers: `45`, `148`, `37`.

## Decision artifact

- Compare three concrete policies on the same untouched site: validate/reject unlucky seeded layouts; reserve one plausible noteworthy encounter within the starting exploration area; or adapt encounter placement after an observed drought. Include the existing unprotected distribution as a baseline.
- Explain fairness, route freedom, rerun variety, spoilers, performance, save identity and what happens if the player intentionally rushes downward or ignores a clue. Do not promise timing from spatial distance alone or silently relocate a saved find.
- Use a named `40`-briefed object, actual starter kit/reach, detector eligibility, recognisable partial silhouette and useful first purchase. Keep every common mineral detector-silent and preserve the finite 1,024-find/value budget by replacement, not extra loot.
- Prepare concrete seeded route sketches and a first-encounter timeline for mixed, vertical and lateral play; estimate first useful upgrade affordability with paid refills. The reports' first-ten-minutes goal is a playtest hypothesis, not a forced time trigger or tutorial lock.
- Recommend one policy or omission and specify generation/retry/save migration implications. If adaptive generation needs a new implementation owner, create the next numeric task after review; do not smuggle it into a probability edit.

## Review and acceptance

The user reviews the concrete policies, named encounter, uncertainty and tradeoffs. Record the choice in the owning generation/content contracts and update `45`/`148`/`37`. Questions alone do not complete this design. No new object import, detector sound, world expansion, pre-dug chamber or scripted compulsory route is authorized by the reports.
