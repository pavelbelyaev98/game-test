# Meltopia lessons and task ownership

Basis: the user's supplied "Meltopia Design Research and Lessons for Our Excavation Game", dated 2026-09-09. This is a retained design synthesis, not independent verification of its review totals, dates or quotations. The attachment's opaque citation tokens are not usable citations; links below retain its provenance. Existing [review findings](player-review-findings.md) remain applicable.

## Implications and owners

| Lesson | Planned work / decision owner |
| --- | --- |
| Terrain removal must be rewarding without loot | `57` briefs contact/fracture/removal/reveal/pickup feedback; `06`/`11` integrate; `15` observes sustained digging. |
| Never reset purchased tool power | `56`/`58` preserve one evolving shovel and old-ground gains; `11`/`39` implement. No mandatory second tool/material reset. |
| Physical upgrade installation | `57` compares brief bolt/motor/blade attachment staging; `11` integrates the selected sequence, with explicit asset approval. |
| Final power needs time to be enjoyed | `56` plans late milestones; `37` tests final meaningful purchase at roughly 75-85% of first-completion time. This is a hypothesis, not a gate. |
| Return friction accumulates | `15`/`59`/`37` separate excavation, return, station and outbound retrace time; inventory + shared battery + geometry suffice. |
| Fun mobility is a reward | `47` tests strong controllable late jetpack travel on matched battery/routes. No extra grapple or mandatory platforming. |
| Player-made tunnels heighten navigation risk | `70` moves immediately after `15`, comparing HOME and 3-5 reusable differentiated markers before waiting for paid late tracks. Both remain proposals. |
| Persistence must not interrupt digging | `80` improves capture/scaling around `35`'s existing asynchronous writer and consistent recovery; `54` qualifies late saves. |
| Physical input accessibility is baseline | `78` delivers complete keyboard/mouse rebinding and free optional toggle dig early, preserving hold default and interruption safety. |
| Visual comfort gaps need delivery | `65` already supplies FOV/steady crosshair; `81`/`82` own brightness and reticle options. No added camera motion merely to add switches. |
| Detector repetition can be grating | `57`/`10` own sparse cues and independently persisted detector volume/mute; `49`/`54` repeat long-session/high-range checks. |
| Distinctive finds need identity | `40` proposes sparse one-line inspection flavor; conditional `83` integrates it. Fridge stays name + depth; no appraisal bureaucracy. |
| Last-find hunting can become empty wandering | `84` reviews late/postgame assistance and its conflict with no-rarity-filter rules; conditional `85` delivers only the selected policy. |
| Geological contrast helps recognition | `58` briefs gradual formations/landmarks with `70`; no rigid biome gates, authored tunnel routes or unapproved decorative props. |
| Explosives need predictable payoff | `71` compares placement ghost/affected-volume preview and large material-sensitive blast examples, with no spend on invalid placement. Still optional. |
| Ending must accelerate the earned fantasy | `61`/`52` use upgraded normal equipment, escalating discoveries and reviewed optional short reactions; `37` checks the final 30-40 minutes. |
| Replay comes from discovery uncertainty | `40`/`45` preserve authored context plus seeded discoveries in the main campaign; no separate endless mode for launch. |
| Preserve future co-op possibility only | `80` keeps stable IDs, seeds and explicit serializable world edits. No networking implementation or launch promise. |

## Preserved exclusions

No mandatory second excavation tool, warmth/oxygen/food meter, grapple, forced platforming, authored material-permission gates, launch endless mode, music or voice acting. Recommendations do not approve models, sounds, final-object copy or optional mechanics. A target fraction or marker count is a test proposal, not a fixed player requirement.
