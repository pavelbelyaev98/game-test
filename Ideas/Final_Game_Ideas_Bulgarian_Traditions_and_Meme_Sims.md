# Final Game-Idea Shortlist
## Memeable tiny simulators + Bulgarian seasonal traditions

**Research date:** September 5, 2026  
**Target:** a small, single-player Unity game built by a solo developer using marketplace assets and heavy AI coding assistance  
**Design objective:** obvious physical verb, strong visual transformation, satisfying progression, minimal NPC/AI complexity, memorable Steam/TikTok hook.

---

# 1. What the research says we should make

After studying:

- *A Game About Digging a Hole*
- *PowerWash Simulator*
- *A Game About Chopping Trees*
- *Leaf it Alone*
- *Librarian: Tidy Up the Arcane Library!*
- *Cash Cleaner Simulator*
- *Prison Escape Simulator: Dig Out*
- *Schedule I*
- *Storage Hunter Simulator*
- *Parcel Simulator*
- *Deconstruction Simulator*
- *My Wife Threw Out My Card Collection*
- *Drywall Eating Simulator*
- and many other simulator games,

the best target for us is no longer “make a simulator.”

It is:

> **Take an ordinary physical activity people immediately understand, give it one ridiculous or culturally specific hook, make the environment visibly transform, and let progression turn painful manual work into absurd efficiency.**

The strongest engines for our game are:

1. **TRANSFORMATION** — the place visibly becomes better/emptier/cleaner.
2. **DISCOVERY** — maybe the next object hides something interesting.
3. **PROCESSING** — one object can pass through several meaningful states.
4. **UPGRADE** — eliminate one bottleneck at a time.
5. **COLLECTION** — some items are worth keeping, not merely selling.
6. **MEME IDENTITY** — title/premise makes someone laugh before playing.

We should usually combine **three or four**, not all six.

# 2. Uniqueness warning

“No close game found” does **not** mean no similar prototype exists anywhere.

The labels below mean:

## STRONG GAP
Targeted Steam/web searches did not reveal a close dedicated commercial game using the full premise.

## DISTINCT WITH NEIGHBORS
Related games exist, but this version has a meaningful identity/mechanical difference.

## CROWDED
Close competitors already exist. We should only proceed with a strong twist.

# FINAL TOP 20

# 1. 🇧🇬 CHUSHKOPEK SEASON
## A Game About Roasting 500 Peppers

### Steam sentence

> Your family has bought an unreasonable number of peppers. Roast them before baba loses patience.

### Core loop

```text
CRATE ARRIVES
→ SORT PEPPERS
→ ROAST
→ TIME PERFECT CHAR
→ STEAM
→ PEEL
→ SEED
→ STACK / JAR / STRING
→ CLEAR NEXT CRATE
```

### Why this is exceptional

The chushkopek is itself a memeable object.

It is a uniquely Bulgarian pepper-roasting appliance and was famously voted Bulgaria's “Household Revolution of the 20th Century” in a Bulgarian National Television campaign.

The visual/audio loop is naturally satisfying:
- hiss;
- pop;
- blackened skin;
- steaming pepper;
- peel slips off;
- finished glossy red pepper.

### Cash Cleaner lesson

One pepper can have many states:

```text
RAW
DIRTY
UNDERRIPE
RIPE
ROASTING
PERFECT
BURNT
STEAMED
PEELED
SEEDED
JAR-READY
DRYING
```

So we get a deep processing loop without 100 object types.

### Progression

Start:
- single-pepper chushkopek;
- tiny tray;
- awful tongs.

Later:
- triple chushkopek;
- bigger table;
- peeling station;
- multi-crate handling;
- giant ridiculous final pepper machine.

### Meme moments

- “BABA APPROVAL: 37%”
- burn three peppers simultaneously;
- neighbor complains about smoke;
- another uncle appears with five more sacks;
- final yard looks like a pepper factory.

### Uniqueness

Targeted searches did not reveal a dedicated commercial pepper-roasting / chushkopek / lyutenitsa-prep simulator.

Adjacent:
- Balkan cooking games;
- broader cooking/farming sims.

**Verdict: STRONG GAP.**

# 2. 🇧🇬 ZIMNINA SEASON
## Prepare the Entire Cellar for Winter

“Зимнина” is the broader household-preservation fantasy.

The entire objective:

> **Fill every cellar shelf before winter.**

### Core activities

Use only processes that share code:

```text
WASH
→ SORT
→ CUT / PREP
→ BOIL / ROAST / BRINE
→ FILL JAR
→ CLOSE
→ LABEL
→ SHELVE
```

Products can include:
- turshiya;
- kompot;
- roasted peppers;
- lyutenitsa;
- preserved tomatoes/vegetables.

### Why this is potentially stronger than five separate games

The shared object pipeline is the game.

Different recipes are **job specifications**, like Cash Cleaner:

> 8 jars mixed turshiya  
> 6 cherry kompots  
> 10 roasted pepper jars  
> 12 lyutenitsa jars.

The pantry/cellar physically fills up.

That is the progress bar.

### Risk

Do **not** add rakia and pig processing into the MVP.

Those require completely different interaction systems.

They can exist later as:
- bonus chapter;
- DLC;
- sequel;
- separate game in the same “Bulgarian Yard Simulator” universe.

### Market check

No dedicated first-person “winter preserves / zimnina” Steam simulator surfaced in targeted searches.

Survival games contain canning/preserving mechanics, but not this entire fantasy.

**Verdict: STRONG GAP.**

# 16. 🇧🇬 RAKIA DAY
## One Day at the Kazan

This should **not** be a generic distillery-management game.

*Moonshine Inc.* already covers fermentation, distillation, recipes, equipment, police pressure and business management.

Our differentiation:

> **one extremely tactile Bulgarian distillation day in first person.**

### Fantasy

Fruit mash has already fermented.

Today is your family's time at the kazan.

### Core loop

```text
PREP EQUIPMENT
→ TRANSFER MASH
→ HEAT
→ WATCH TEMPERATURE / FLOW
→ COOL
→ COLLECT BATCH
→ SEPARATE QUALITY PHASES
→ MEASURE
→ BOTTLE
→ LABEL / STORE
```

Keep this **gamey and simplified**, not a technical real-world instruction manual.

### Meme layer

- grandfather insists he can judge quality by smell;
- everyone has a different opinion;
- endless reused bottles;
- absurd hand-written labels;
- kazan day becomes a social ritual.

### Progression

A single session can move:
- improvised tools;
- better containers;
- better thermometer/interface;
- improved cooling;
- faster bottling;
- final beautiful copper setup.

### Market check

**Moonshine Inc. is a direct thematic neighbor**, so “making alcohol” is not unique.

The Bulgarian one-day physical/ritual framing is the differentiator.

**Verdict: DISTINCT WITH A MAJOR NEIGHBOR.**

# 17. 🇧🇬 TURSHIYA DAY
## The Jar Must Be Perfect

A first-person seasonal preserving game built around vegetables and brine.

### Objects

- peppers;
- carrots;
- cauliflower;
- celery;
- garlic;
- green tomatoes;
- other seasonal vegetables.

Traditional Bulgarian turshiya can contain mixed vegetables, and ethnographic work on Bulgarian cellar preservation documents jars containing combinations such as peppers, carrots, celeriac, garlic, vinegar, salt and sugar.

### Game loop

```text
WASH
→ INSPECT
→ CUT
→ PACK JAR BEAUTIFULLY
→ MIX / ADD BRINE
→ SEAL
→ LABEL
→ SHELVE
```

### Why it can work

Packing the jar can become a tiny spatial optimization puzzle.

Perfect arrangement:
- bonus score;
- more vegetables fit;
- better visual result.

### Progression

Hand cutting → slicer → prep tray → multi-jar station → filling funnel → labeling jig.

### Market check

A 2026 game named **Pickle Simulator** exists, but it is a parody where the player *is a pickle*; it is not a pickling/canning simulator.

Targeted searches did not reveal a dedicated first-person pickling/turshiya-production simulator.

**Verdict: STRONG GAP.**

# 19. 🇧🇬 PIG DAY
## Traditional Winter Processing Day

There is a real Bulgarian winter tradition of household pig slaughter/processing around the Christmas period; Bulgarian dialectology archives include first-person descriptions from Bansko discussing pig slaughter before Christmas and subsequent processing.

This is culturally real—but as a game concept it needs careful positioning.

### Do not build a graphic killing simulator

For broader appeal and lower art/animation burden:

> **start after the slaughter, with the carcass already prepared for processing.**

The game is about:
- organizing tools;
- dividing cuts;
- sorting usable parts;
- grinding;
- seasoning;
- stuffing sausage;
- hanging/curing;
- labeling/freezer/storage;
- cleaning the work area.

### Why this is more interesting

Cash Cleaner structure:

one raw input → many processing states / outputs.

### Progression

Manual grinder → better grinder → sausage filler → improved racks → storage/freezer organization.

### Meme angle

The family has one objective:

> **NOTHING IS WASTED.**

Every table in the yard becomes part of the operation.

### Market check

This is **not an empty market**:
- *Butcher Simulator* is announced and focuses on carcass cuts and a butcher business.
- *Ranch Simulator* already contains animal slaughter/processing mechanics.

The Bulgarian one-day winter-family-processing ritual is differentiable, but the main verb overlaps.

**Verdict: CROWDED MECHANIC / UNIQUE CULTURAL FRAMING.**

If choosing between this and peppers, I choose peppers.

# 5. What should probably be separate

## Rakia

Needs:
- fermentation/distillation abstraction;
- liquid/heat/measurement systems;
- different visual equipment;
- alcohol framing.

## Pig processing

Needs:
- cutting/meat processing;
- very different assets;
- mature/gore considerations;
- potentially narrower audience.

They can share the *setting*, but not enough of the main interaction code.

For the first game, they are scope traps if bundled into Zimnina Season.

# 11. The “would I rather watch than buy?” test

*Drywall Eating Simulator* warns us about this.

A funny title can generate clicks.

But the buyer needs tactile ownership.

For each concept ask:

### Watching
What is funny/interesting?

### Playing
What can I personally optimize/master?

Example Chushkopek:

Watching:
> baba judges burnt pepper.

Playing:
> perfect roasting timing + batch routing + peel efficiency + yard workflow.

That is what converts meme into game.

# 13. Hard scope for the pepper prototype

Do not build the whole game first.

Build:

```text
ONE SMALL YARD
ONE CHUSHKOPEK
ONE PEPPER CRATE
ONE PEPPER STATE MACHINE
ONE PERFECT-ROAST WINDOW
ONE BURNT STATE
ONE STEAM BOWL
ONE PEEL ACTION
ONE FINISHED TRAY
ONE CASH / SCORE COUNTER
ONE UPGRADE
```

20-minute version.

The test:

> **Is roasting → steaming → peeling 20 peppers satisfying?**

If yes, expand.

If no, stop.
