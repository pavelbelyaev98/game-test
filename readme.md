# Something Down There

First-person excavation game built in Unity. Source checkout requires **Git LFS** for editable 3D art assets (`git lfs install --local` and `git lfs pull`).

## Play

Launch [SomethingDownThere.exe](builds/windows/SomethingDownThere.exe). You do not need Unity to run and test the latest build.
